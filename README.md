# Padovani Advisory

Sito ufficiale responsive di Padovani Advisory, realizzato con il logo fornito e una direzione visiva ispirata ai riferimenti condivisi.

## Sezioni

Home, Cosa affrontiamo, Metodo, Osservatorio, Chi siamo e Contatti.

Il progetto è in fase di avvio e raccoglie richieste informative. Il sito non presenta consulenze come già operative; il modulo prepara un'email e non archivia dati.

## Struttura

- `index.html` — contenuti e struttura della pagina
- `styles.css` — stile responsive
- `script.js` — navigazione mobile e modulo contatti
- `public/` — logo ufficiale e immagini ottimizzate
- `vercel.json` — configurazione per deploy statico

## Deploy

Il progetto è pronto per Vercel. Installa l'integrazione GitHub di Vercel per questo repository e seleziona la cartella root; il progetto usa HTML, CSS e JavaScript statici, senza comando di build.
